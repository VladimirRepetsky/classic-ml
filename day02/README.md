## Ключевые концепции

### Нормальное уравнение (МНК)
```
w = (XᵀX)⁻¹Xᵀy
```
Аналитическое решение. Используется внутри `LinearRegression().fit()`.

### Градиентный спуск
```
w ← w - α · ∂MSE/∂w
b ← b - α · ∂MSE/∂b
```
Итеративная оптимизация. Основа обучения нейросетей.

### Масштабирование признаков
```
X_scaled = (X - mean) / std
```
Критично для градиентного спуска. Позволяет сравнивать веса.

### Утечка данных
Масштабировать только на обучающей выборке. Применять ту же трансформацию к тесту.

## Результаты

- МНК вручную совпадает со встроенным в sklearn
- Градиентный спуск сходится к тому же решению
- Без масштабирования градиентный спуск работает плохо
- После стандартизации веса можно сравнивать

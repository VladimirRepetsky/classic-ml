## Ключевые концепции

### Полиномиальная регрессия
```python
from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(degree=3)
X_poly = poly.fit_transform(X)
```
Полиномиальная регрессия — это ВСЁ ЕЩЁ линейная модель. Мы просто добавляем новые признаки (x², x³, ...).

### Переобучение и недообучение

| Ситуация | Train MSE | Test MSE | Диагноз |
|---|---|---|---|
| Недообучение | Высокая | Высокая | Модель слишком простая |
| Хорошая модель | Низкая | Низкая | Баланс найден |
| Переобучение | Очень низкая | Высокая | Модель слишком сложная |

### Компромисс смещения и дисперсии
```
Общая ошибка = Смещение² + Дисперсия + Неустранимый шум
```

### Три выборки
- **Обучающая** (train): модель учится
- **Валидационная** (validation): выбор гиперпараметров
- **Тестовая** (test): финальная оценка (ОДИН РАЗ)

## Результаты

- Полиномиальная регрессия лучше описывает нелинейные зависимости
- Степень полинома — гиперпараметр, подбирается через валидацию
- Переобучение лечится: регуляризация, больше данных, уменьшение сложности
